# Input Notes

- Cluster 1: early studies focused on model accuracy in controlled datasets.
- Cluster 2: later studies moved to clinical interpretability and trust.
- Wang 2020: high classification accuracy, but no explanation module.
- Ibrahim 2021: added saliency maps, but clinicians found them unstable.
- Kumar 2022: argued interpretability should be evaluated with users, not only metrics.
- Li 2023: mixed-method study, clinicians valued consistency more than visual complexity.
- General pattern: field shifted from performance-first to usability-aware design.
- Gap: still limited agreement on how to evaluate interpretability in real workflows.
