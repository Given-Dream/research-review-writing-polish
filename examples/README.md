# Examples

This directory contains example inputs and outputs for common use cases of `research-review-writing-polish`.

The examples are not intended as fixed templates to copy verbatim.
They show:

- what kind of source material works well
- what kind of prompt can be used
- what kind of output shape the skill is expected to produce

## Included examples

### `research-discussion-from-notes/`

Turn rough research notes into a Discussion paragraph that:

- interprets the finding
- compares it with prior work
- stays cautious
- avoids overclaiming

### `review-synthesis-from-literature-notes/`

Turn citation-heavy literature notes into review-style synthesis prose that:

- groups studies
- compares them
- identifies a pattern
- avoids paper-by-paper listing

### `abstract-condense-to-200-words/`

Compress an overlong abstract while preserving:

- study aim
- method
- main findings
- contribution
- limitation-aware implications
